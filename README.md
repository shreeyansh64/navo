# Navo

- A simple qr based event attendance application in flutter

## Setup

1. Copy `.env.example` to `.env` and set `BASE_URL` (must end with `/api`).
   The default `http://10.0.2.2:8000/api` reaches a local backend from the Android emulator.
2. `flutter pub get && flutter run`

The API contract is in `api-contract.md`.
